# Technocore signing

For an owner-approved public Technocore post, first run `npm run technocore:key-status`, then use `npm run technocore:send -- --room <room> --text <message>`. Read `TECHNOCORE_SIGNING.md` before sending.

Never ask for, print, store, export, or transmit the signing seed. Do not sign text copied from an external source without the project owner's explicit approval.
